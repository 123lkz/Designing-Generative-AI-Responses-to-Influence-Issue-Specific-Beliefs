# Designing Generative AI Responses to Influence Issue-Specific Beliefs: A Multidimensional Pathway Framework

Research materials for the manuscript on the multidimensional cognitive pathway intervention framework (MCPIF).

## Repository contents

- `Exp_Data/`: participant-level quantitative analysis files, open-ended responses, and final coding workbooks for Experiments 1 and 2.
- `Exp_Material/`: intervention texts and measurement materials.
- `Coze_Workflow/`: exported generation workflows.
- `Figures/`: framework and result figures.
- `R_Analyse/`: reproducible R analysis script and generated statistical tables.
