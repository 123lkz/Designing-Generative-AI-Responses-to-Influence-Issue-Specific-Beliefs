# Designing Generative AI Responses to Influence Issue-Specific Beliefs

Research materials for the manuscript on the multidimensional cognitive pathway intervention framework (MCPIF).

## Repository contents

- `Exp_Data/`: participant-level quantitative analysis files, open-ended responses, and final coding workbooks for Experiments 1 and 2.
- `Exp_Material/`: intervention texts and measurement materials.
- `Coze_Workflow/`: exported generation workflows.
- `Figures/`: framework and result figures.
- `R_Analyse/`: reproducible R analysis script and generated statistical tables.

## Reproduce the analyses

Install the required R packages once:

```r
install.packages(c("readxl", "mvtnorm"))
```

Then run from this repository's root directory:

```sh
Rscript --vanilla R_Analyse/run_analysis.R
```

The script reads the four `*_for_R.csv` files and the `最终编码` sheet in each `*_coding.xlsx` workbook under `Exp_Data/`. Outputs are written to `R_Analyse/results/`; rerunning overwrites generated outputs but does not change the input data. An optional first command-line argument specifies the project root, and an optional second argument specifies the output directory.

Experiment 1 analyses include descriptive statistics, ANOVAs, PBS/CFI ANCOVAs, Dunnett comparisons, and regressions of PBS, CFI and BCIS outcomes. Experiment 2 uses a separate-slopes ANCOVA with HC3 standard errors, adjusted means at the grand pretest mean with equal weighting across topics, and Holm-adjusted overall and within-topic contrasts. Supplementary gain-score analyses and final-code open-response summaries/tests are also included. Blank responses are excluded separately by question; explicit answers such as "none" are retained. The analysis script documents the exact comparison families.

PBS files contain summed scores rather than item responses. Item-level reverse scoring and reliability, recruitment/randomization procedures, and Experiment 1 exclusions cannot be reconstructed from these analysis files. Final qualitative codes are read as supplied, not regenerated by the script.

The script was run with R 4.5.3, `readxl` 1.4.5 and `mvtnorm` 1.3-6. All 28 input checks passed. A separate Python audit passed 59 numerical comparisons, including the primary quantitative results and open-response tests. `results/independent_validation.csv` records that audit and is not regenerated by the R script. `results/input_manifest.csv` records input fingerprints; running the script also generates `results/sessionInfo.txt` with the execution environment. Dunnett integration can vary slightly in the last digits across platforms.
